## 도구 검토와 보완

- 읽기 전용 독립 리뷰에서 현재 정상 VU 1 측정 경로의 차단 문제는 발견되지 않았다.
- 실패·시간 부족 실행이 조건 평균에 섞이는 문제, FCM 대상 누락·중복 검증, 보고서 표본 수 검증을 회귀 테스트 RED→GREEN으로 확인. 집계·보고서 검사 8개 통과.
- 시작 실패·정상 종료 실패 시 소유한 벤치마크 JVM만 정리하도록 PID 기록·명령행·생성 시각 검증 추가. 중복 실행은 파일 잠금으로 차단. 이 보완은 실행 중 JVM에 소급 적용되지 않는다.
- CPU·heap은 앱과 WireMock을 합친 JVM 값이다. 로그인·JWT·Google 인증 등 전체 운영 경로의 성능으로 해석하지 않는다.
- 캠페인 시작 시 스키마 초기화 후 같은 JVM에서 순서대로 실행한다. 매 요청 데이터는 다르지만 이전 실행 행은 캠페인 종료까지 남는다.
- 원래 작업 폴더의 기존 변경(`run-baseline-tests.ps1`, `BaselineReproductionTest.java`)과 사용자 Word 파일은 보존한다.
